# Support

Turnkeeper's public packages are pre-release software. Community support is provided on a
best-effort basis, and response times are not guaranteed.

## Where to ask

- Use [GitHub Discussions](https://github.com/turnkeeper-ai/turnkeeper-js/discussions) for setup,
  usage, design questions, and integration guidance.
- Use [GitHub Issues](https://github.com/turnkeeper-ai/turnkeeper-js/issues/new/choose) for
  reproducible SDK, CLI, MCP, skill, example, and documentation defects.
- Send suspected vulnerabilities privately to `support@turnkeeper.ai` as described in
  [SECURITY.md](SECURITY.md).
- Send hosted dashboard, organization, billing, cloud storage, and production infrastructure
  questions to `support@turnkeeper.ai`; those systems are not implemented in this repository.

## Include in public reports

- The affected package and exact version
- Node.js, npm, and operating-system versions
- A minimal reproduction using synthetic data
- Expected and actual behavior
- Relevant secret-free logs or error codes

Never publish API keys, customer content, production identifiers, private endpoints, exploit
payloads, internal runbooks, or private strategy.

## Maintainer response

Maintainers triage public reports by reproducibility, safety, compatibility impact, and alignment
with the [public roadmap](ROADMAP.md). A report may be redirected to a discussion, closed as out of
scope, or held until the required public server contract exists.
